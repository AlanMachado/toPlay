# toPlay

Playground para praticar e ficar melhor usando o [Claude Code](https://claude.com/claude-code).

A ideia é ter um espaço livre para experimentar: pedir features, refatorações,
revisões de código, testes, automações etc., sem medo de quebrar nada importante.

## Estrutura

```
.
├── CLAUDE.md        # instruções e contexto para o Claude neste repositório
├── experiments/     # cada experimento fica em sua própria pasta
└── README.md
```

## Como usar

1. Crie uma pasta em `experiments/` para cada ideia (ex.: `experiments/todo-cli/`).
2. Peça ao Claude para implementar, testar ou revisar algo ali dentro.
3. Anote no README do experimento o que funcionou bem e o que não funcionou.

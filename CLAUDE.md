# CLAUDE.md

Este repositório é um playground para aprender a trabalhar com o Claude Code.

## Convenções

- Cada experimento vive em sua própria pasta dentro de `experiments/`, com um `README.md`
  explicando o objetivo e como rodar.
- Não há stack fixa: escolha a linguagem/ferramenta adequada a cada experimento e
  mantenha as dependências isoladas na pasta dele.
- Prefira mudanças pequenas e commits com mensagens claras.
- Se um experimento tiver testes, rode-os antes de commitar.
